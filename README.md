# 🍽️ Eat Fresh

### A modern and responsive food landing page built with HTML5 and CSS3.

🌐 **Live Demo**

[Visit : Eat Fresh](https://bayjid-alom.github.io/eat-fresh/)

### 📖 About The Project

Eat Fresh is a modern and responsive food landing page designed for a healthy food brand. The project features a clean hero section with an engaging headline, a call-to-action button, and a visually appealing food-themed banner.

The main goal of this project is to practice HTML5 structure, CSS3 styling, responsive layouts, and modern web design techniques while creating a simple and attractive landing page.

## ✨ Features

* Responsive Design
* Modern Hero Banner
* Healthy Food Theme
* Clean UI Layout
* Mobile-Friendly Interface
* Custom CSS Styling
* Google Fonts Integration
* Font Awesome Icons
